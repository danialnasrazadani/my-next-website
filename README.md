🌐 My Next Website

A modern and responsive web application built with Next.js and React, featuring a login page, dashboard, authentication state management, and a structured data layer.

✨ Features

* 🔐 Login page
* 📊 Dashboard
* 🔑 Authentication state management with React Context
* 🗂️ JSON-based data structure
* 🎬 Smooth animations with Framer Motion
* 📱 Responsive design for desktop and mobile
* 🧩 Component-based project structure

🛠️ Technologies

* Next.js 15
* React 19
* JavaScript
* Framer Motion
* CSS
* JSON

🚀 Getting Started

Clone the repository

git clone https://github.com/danialnasrazadani/my-next-website.git

Install dependencies

npm install

Run the development server

npm run dev

Then open the local URL provided by Next.js in your browser.
